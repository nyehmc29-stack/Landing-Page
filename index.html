Frequently Asked Questions

Apakah top up langsung masuk ke akun?

Setelah pembayaran terverifikasi, proses top up akan diproses. Landing page ini merupakan prototype sehingga belum terhubung ke payment gateway atau API game.

Game apa saja yang tersedia?

Saat ini prototype menyediakan Mobile Legends, Free Fire, Roblox, dan Valorant.

Apakah pembayaran aman?

Untuk versi production, gunakan payment gateway resmi dan jangan menyimpan data sensitif pembayaran secara langsung di website.

Bagaimana jika salah memasukkan ID?

Selalu periksa kembali ID pemain sebelum melakukan pembayaran. Prototype ini menampilkan peringatan sebelum checkout.
